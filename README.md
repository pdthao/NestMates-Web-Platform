# NestMates — Connect, Grow, Thrive

A frontend web design project that presents a community-focused housing platform for people looking for comfortable, clean, and safe shared living spaces.

**[View Live Website](https://pdthao.github.io/NestMates-Web-Platform/)** · **[View Source Code](https://github.com/pdthao/NestMates-Web-Platform)**

## Project Overview

NestMates was developed as a **Web Programming course project**. The goal was to design and build a housing website concept with a recognizable name and visual identity, clear navigation, accommodation information, and ways for visitors to explore a community-oriented living experience.

The concept emphasizes connection between residents, accessible housing information, and saving time when comparing different living arrangements.

## Features

- **Landing page:** Introduces the NestMates concept and invites visitors to explore.
- **About section:** Explains the platform's mission and the appeal of community-based housing.
- **Accommodation listings:** Displays housing categories, images, descriptions, sample prices, and contract periods.
- **Resident reviews:** Presents feedback-style content about accommodation experiences.
- **Contact form interface:** Collects visitor details and messages through a web form. Backend message delivery is not documented in this repository.
- **Navigation and page sections:** Organizes content so visitors can browse the website.

## Technologies Used

- **HTML5** — page structure and content
- **CSS3** — styling and visual layout
- **JavaScript** — client-side scripting
- **GitHub Pages** — static website hosting

## Design Objectives

1. Create a clear housing-platform identity with readable content and visual consistency.
2. Present several accommodation options in an approachable layout.
3. Highlight trust, community, safety, and convenience in the website concept.
4. Practice frontend development and organization of HTML, CSS, JavaScript, and image assets.

## Project Scope

This repository showcases the **frontend website prototype** developed for a course assignment. The property descriptions, prices, reviews, and contact details shown on the site are presentation content; they should not be interpreted as verified live rental offers. A production booking system, database, and working contact backend are not established by the source materials.
